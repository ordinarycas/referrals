What is a referral code? How it works

A referral code, also called an invite code or invitation code, is a short code you enter when you sign up: platforms use it to control who can register or to record who recommended you. An invite link usually carries the code already.

What is a referral code?

A referral code is a code you enter when you sign up, and it is used in two common ways:

  • Registration control: only people who received an invitation can sign up. It can cap the number of members, keep out mass sign-ups, or let a few people try a service before it opens. These codes are usually issued by administrators and are often single-use (see the references at the end).
  • Referral: the code records who recommended you, and the platform then rewards the referrer, the new member or both under its own rules.

On most platforms "invite code" and "referral code" mean the same thing. An invite link is a web address that usually already carries the code, so the sign-up page often fills it in; when a link carries no code, you type or paste it yourself.

Referral code, invite code, invitation code: what is the difference?

Platforms do not name this code consistently. You will see referral code, invite code, invitation code and share code, and "invite friends" as the name of a feature. A different name does not always mean a different function, so check the platform's own description. Roughly:

  • Invite code or invitation code: traditionally about access, letting only invited people sign up; many platforms now use the same name for the code that records a referral.
  • Referral code: about tracking and rewards. It records who recommended you, and the platform rewards people under its own rules.
  • Share code: a looser term, usually the code a member shares with friends. What it does depends on the platform.
  • Invite friends: usually the name of a feature in an app or website where you find your own code and link, share them and follow your invitations.
  • Promo code or discount code: takes money off a purchase and usually does not record a referrer, so it is a different thing.

On most platforms a referral code, an invite code and a share code are the same code, so go by the field name on the sign-up page. This site mostly writes "referral code"; where the data records another name used by a platform, that platform's page says so.

How does a referral code work?

A code is usually tied to your account when you register: you enter it, or you open the sign-up page from an invite link, and the platform records the referrer. Whether you can add one later depends on the platform.

Rewards usually come with conditions, such as identity verification, qualifying spending, a time limit and region. Two examples this site checked against the official pages on October 25, 2026:

  • ShopBack: when conditions are met, both the referrer and the new member get a reward. The terms require the new member, within 180 days of registering, to complete qualifying orders through ShopBack and have the cash back turn "Confirmed"; the invitation counts only when every condition is met.
  • ether.fi: the official referral scheme is an affiliate program. Its terms require signing up through the link, activating the card and making a qualifying purchase; no reward specific to the invited person is stated.

Actual conditions and amounts follow each platform's announcements.

What should I check before using a referral code?

Check the link domain, update date, region limits and the platform's terms before you use a code:

  • Link domain: the sign-up address should be one of the platform's official domains. Every entry on this site lists its "Link domain"; compare it before you register.
  • Update date: codes and campaigns can change or end at any time. Entries not updated for more than 180 days are marked "May be out of date".
  • Region and regulatory notices: some platforms serve only certain regions or carry a regulator's warning. For example, this site's Pionex page keeps a warning from Taiwan's Securities and Futures Bureau (listed on an association website): not registered under the Company Act, so it may not serve or solicit in Taiwan.
  • Platform terms: self-referral, multiple accounts and some ways of promoting a link are often banned; the terms of ShopBack and ether.fi both prohibit self-referral.
  • Safety: never pay for a code, and never hand your password or verification codes to anyone.

Frequently asked questions

Platform rules differ. These are common practices, so check the platform's terms.

Where do I enter a referral code, and where do I find my own?

Usually in the "Referral code", "Invite code" or "Referrer" field on the sign-up page. If you opened the sign-up page from an invite link, the field is often filled in already. Some platforms let you add a code after signing up, in your profile or settings, but not all do. Your own code is usually on an "Invite friends" or "Refer" page in the app, though the name varies by platform.

What does "invite friends" mean?

It is usually the name of a feature in an app or website where you can see your own code and invite link, share them with friends and follow the progress and rewards of your invitations. This site lists the codes and links that this kind of feature gives out.

Is a referral code the same as a promo code or discount code?

No. A referral code records or limits who recommended you, while a promo or discount code takes money off a purchase and usually has nothing to do with a referrer. Some platforms pay referral rewards as coupons; the actual terms follow the platform's announcements.

What is the difference between a referral code and an affiliate program?

A referral code usually comes from a program in which ordinary members recommend the platform. An affiliate program is more often aimed at creators, bloggers and promotion sites, and pays commission on results. Both can track with a code or a link, and the name is whatever the platform uses; for example, ether.fi's official referral scheme is an affiliate program.

Can I enter my own referral code?

Usually not: the platform may withhold the reward or cancel eligibility. The terms of ShopBack and ether.fi both prohibit self-referral.

Do referral codes expire?

They can. A code may have a time limit, and it may stop working when a campaign ends or the platform changes its rules.

Can I add or correct a code after signing up?

Not always. Some platforms only recognize the referrer attached at registration, so check that the code field is filled in or pasted before you register.

Can a referral code be used only once?

Not necessarily. A code that works as an entry pass is often one person per code; a code for recommending the platform can usually be used by several friends, though some platforms limit the number of people or the time.
