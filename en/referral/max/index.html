What is MAX?

MAX is a digital asset exchange run under MaiCoin (the site footer is signed 現代財富科技股份有限公司). Its site description says it offers popular trading pairs such as Bitcoin, Ether and USDT and that funds are held in trust; this is the platform's own statement, and this site has not checked the trust arrangements. The official statutory disclosures page also lists documents such as the anti-money-laundering registration approval number and date, the fee policy, the information security policy, trust bank information for fiat assets and proof-of-reserves reports, which are worth reading before you sign up. MaiCoin also runs a physical store in Taipei (No. 104, Sec. 1, Bade Rd., Zhongzheng Dist., Taipei City) that offers platform introductions, beginner tutorials and help with opening an account.

The referral link on this page already carries the referral code 89225d4a (the r parameter in the address). On 2026-10-28 this site opened the link in the English interface, and the sign-up page showed that someone invites you to join MAX ("Invite you to join MAX"). The official referral program page calls the code a "referral code" (推薦碼) while the share page says "invitation code" (邀請碼); they are the same code.

According to the official Super Referral Program page (read on 2026-10-28): an invited user gets a 20% trading fee discount for six months after registering. The referrer earns a 20% rebate on the friend's trading fees, which can rise to 50% when 5,000 MAX Tokens or more are locked, always paid in MAX Token, and the referrer is rewarded only after the invited user has traded. If the code was not filled in at sign-up, it can be added afterwards (go to User, then Share referral link, then Set referrer); once set it cannot be changed, and you can only bind someone who registered earlier than you. The discount period still runs six months from the registration date, not from the day the code is added.

MAX may change rebate rates and rules at any time and keeps the final right of interpretation; abnormal activity can cancel rebates and discounts. Actual terms, amounts and deadlines follow MAX's official announcements. Before you sign up, check that the domain in the address bar is an official domain under maicoin.com.
