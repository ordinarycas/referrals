招待コードとは？紹介コードの仕組みを解説

招待コードは、登録時に入力するコードで、プラットフォームが登録できる人を管理したり、誰の紹介で登録したかを記録したりするために使います。紹介コードや友達紹介コードも同じものを指すことが多く、招待リンクには通常そのコードがすでに含まれています。

招待コードとは？

招待コードは登録時に入力するコードで、主な使い道は2つあります。

  • 登録の管理：招待された人だけが登録できるようにして、人数を絞ったり、大量登録を防いだり、正式公開の前に一部の人に試してもらったりします。管理者が発行し、1回しか使えないことも多くあります（末尾の参考資料を参照）。
  • 紹介：誰に紹介されたかを記録し、プラットフォームが独自のルールで、紹介した人、新規会員、またはその両方に特典を提供します。

「招待コード」と「紹介コード」は、多くのプラットフォームで同じものを指します。「招待リンク」はURLで、通常コードがすでに含まれており、登録画面に自動入力されるのが一般的です。コードが含まれないリンクでは、自分で入力するか貼り付けます。

招待コード・紹介コード・友達紹介コードの違いは？

このコードの呼び方はプラットフォームによって異なります。招待コード、紹介コード、友達紹介コード、シェアコードなどがあり、機能名として「友達を招待」と呼ぶこともあります。呼び方が違っても機能が違うとは限らないので、各プラットフォームの説明で確認してください。おおまかな違いは次のとおりです。

  • 招待コード：もともとは「入場」を管理するもので、招待された人だけが登録できるようにします。最近は紹介用のコードもこの名前で呼ぶプラットフォームが多くあります。
  • 紹介コード：「追跡と特典」が中心で、誰に紹介されたかを記録し、プラットフォームが独自のルールで特典を提供します。
  • 友達紹介コード・シェアコード：やや広い呼び方で、会員が友人に共有するコードを指すのが一般的です。用途はプラットフォームによって異なります。
  • 友達を招待：アプリやサイトの機能名であることが多く、自分のコードやリンクの確認、友人への共有、招待状況の確認ができます。
  • プロモコード・割引コード：購入金額を割り引くもので、通常は紹介者を記録しません。招待コードとは別のものです。

多くのプラットフォームでは、招待コード・紹介コード・友達紹介コードは同じコードを指します。登録画面の入力欄の名前を基準にしてください。当サイトでは主に「紹介コード」または「招待コード」と表記し、データに別の呼び名が記録されているプラットフォームは、そのプラットフォームのページに記載しています。

招待コードの仕組みは？

招待コードは通常、登録時にアカウントと結び付けられます。コードを入力するか、招待リンクから登録画面を開くと、プラットフォームが紹介した人を記録します。登録後に追加できるかどうかは、プラットフォームによって異なります。

特典には、本人確認、対象となる利用、期限、地域などの条件が付くのが一般的です。当サイトが2026年10月25日に公式ページと照合した2つの例です。

  • ShopBack：条件を満たすと、紹介した人も新規会員も特典を受け取れます。規約には複数の条件があり、新規会員が登録から 180 日以内に ShopBack を通じて対象の注文を完了すること、キャッシュバックが「確認済み」になることなどを含め、すべて満たして初めて招待が成功となります。
  • ether.fi：公式の紹介制度はアフィリエイトプログラムです。規約ではリンクからの登録、カードの有効化、対象となる利用が必要とされ、招待された人だけの特典は記載されていません。

実際の条件や金額は、各プラットフォームの公式発表に従います。

招待コードを使う前に確認することは？

リンク先ドメイン、更新日、対象地域、プラットフォームの規約を確認してから、招待コードを使いましょう。

  • リンク先ドメイン：登録ページのURLが、プラットフォームの公式ドメインであることを確認します。当サイトは各項目に「リンク先ドメイン」を表示しているので、登録前にご確認ください。
  • 更新日：招待コードやキャンペーンは、いつでも変更・終了する可能性があります。180 日以上更新されていない情報には「情報が古い可能性があります」と表示します。
  • 対象地域と規制当局の警告：特定の地域でしか使えないプラットフォームや、規制当局が警告を出しているものがあります。たとえば当サイトの Pionex のページには、台湾の証券先物局の警告（業界協会のサイトに掲載）が載っています。会社法に基づく登録がなく、台湾でのサービス提供や勧誘はできないとしています。
  • 規約：自分で自分を招待すること、複数アカウント、一部の宣伝方法は禁止されていることが多く、ShopBack と ether.fi の規約はともに、自分で自分を招待することを禁止しています。
  • 安全：招待コードを有料で買わないでください。パスワードや認証コードも、誰にも渡さないでください。

当サイトは招待コードをどう掲載していますか？

当サイトは各プラットフォームの紹介コードと登録リンクを1か所にまとめ、各項目に「リンク先ドメイン」と更新日を表示しています。登録前に見比べてください。

「登録する」を押すと、プラットフォームが提供するリンクを新しいタブで開きます。当サイトがリンクを書き換えることはありません。プラットフォームのコードがリンクに含まれていない場合は、先にコードをコピーしますので、登録画面で貼り付けてください。

本サイトには紹介リンクが含まれます。登録されると、当サイトが報酬を受け取る場合があります。報酬や特典の内容は、各プラットフォームの規約で決まります。詳しくはフッターの「サイトについてと開示事項」をご覧ください。

よくある質問

プラットフォームごとにルールが異なります。以下は一般的な例ですので、各プラットフォームの規約をご確認ください。

招待コードはどこに入力しますか？自分のコードはどこで確認できますか？

通常は登録画面の「招待コード」「紹介コード」「紹介者コード」などの入力欄に入力します。招待リンクから登録画面を開いた場合は、すでに入力されていることが多いです。登録後にプロフィールや設定の画面で入力できるプラットフォームもありますが、できるとは限りません。自分のコードは、アプリの「友達を招待」や「紹介」のページにあることが多く、名前はプラットフォームによって異なります。

「友達を招待」とは何ですか？

アプリやサイトにある機能の名前であることが多く、自分の招待コードや招待リンクを確認し、友人に共有し、招待の進み具合や特典を確認できます。当サイトが掲載しているのは、こうした機能で配られるコードとリンクです。

招待コードはプロモコードや割引コードと同じですか？

同じではありません。招待コードは誰の紹介かを記録したり、登録できる人を絞ったりするためのものです。プロモコードや割引コードは購入金額を割り引くもので、通常は紹介者と関係ありません。紹介の特典をクーポンで提供するプラットフォームもあり、実際の条件は各プラットフォームの公式発表に従います。

招待コードとアフィリエイトプログラムの違いは？

招待コードは、一般の会員が友人にプラットフォームを勧める紹介制度から配られるのが一般的です。アフィリエイトプログラムは、クリエイターやブログ、紹介サイトを主な対象にして、成果に応じた報酬を支払う仕組みであることが多いです。どちらもコードやリンクで追跡でき、呼び名はプラットフォームによります。たとえば ether.fi の公式の紹介制度はアフィリエイトプログラムです。

自分の招待コードを自分で入力できますか？

通常はできません。特典が提供されなかったり、資格が取り消されたりすることがあります。ShopBack と ether.fi の規約は、ともに自分で自分を招待することを禁止しています。

招待コードに有効期限はありますか？

有効期限が設けられている場合があります。キャンペーンの終了やルール変更で使えなくなることもあります。

コードを間違えたり入力しなかったりした場合、後から追加できますか？

できるとは限りません。登録時に結び付けた紹介者しか認めないプラットフォームもあります。登録前に、コード欄にコードが入力または貼り付けされているか確認すると安心です。

招待コードは1回しか使えませんか？

そうとは限りません。入場用の招待コードは1人1コードのことが多く、紹介用のコードは通常、複数の友人が使えますが、人数や期間に上限を設けるプラットフォームもあります。
