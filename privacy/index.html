隱私權政策

未經您同意，本站自己不設定 Cookie；沒有帳號與表單，也不自行蒐集個人資料。以下說明儲存在您裝置上的資料、流量統計（含需要您同意的 Google Analytics），以及託管本站的服務。

摘要

  • 未經您同意，本站不設定 Cookie；沒有帳號與表單，也不要求您提供個人資料。
  • 為了解整體流量，本站使用 Cloudflare Web Analytics。Cloudflare 表示，這項統計不使用 Cookie，也不跨網站追蹤個別訪客。
  • 您按下「同意」之後，本站才會載入 Google Analytics 並設定 Cookie；不同意或沒有選擇，就不會載入任何 Google 的程式。隨時可以在頁尾的「統計設定」改變決定。
  • 主題、收藏等偏好只存在您自己的裝置，不會傳送到任何伺服器。

儲存在您裝置上的資料

為了記住您的選擇，本站在瀏覽器的儲存空間保存少量資料。這些資料留在您的瀏覽器裡，本站不會上傳，也不會要求您輸入個人資料。搜尋文字另見下方「流量統計」的說明。

儲存的項目

前六項保留到您自行清除為止（流量統計的選擇滿 180 天會再詢問一次），最後一項在關閉分頁時清除。

  • rs:v1:favorites（localStorage）：收藏的平台，最多 100 筆。
  • rs:v1:view（localStorage）：清單的檢視方式。
  • rs:v1:theme（localStorage）：色彩主題（跟隨系統、淺色或深色）。
  • rs:v1:palette（localStorage）：配色（少女粉、簡潔白或天空藍）。
  • rs:v1:inapp-dismissed（localStorage）：您在 App 內建瀏覽器的提示上按過「不再顯示」。
  • rs:v1:consent（localStorage）：您對流量統計按的是「同意」或「不同意」，以及按下的日期。
  • rs:v1:session:filters（sessionStorage）：本次瀏覽的搜尋文字、篩選、排序與頁碼。

清除方式

按頁尾的「清除本站儲存資料」，會刪除以上全部項目，主題與配色也回到預設；您對流量統計的選擇也會清掉（下次再詢問），已經設定的 Google Analytics Cookie 一併移除。也可以在瀏覽器的網站資料設定中清除。

離線副本

為了在沒有網路時也能閱讀，本站會把您瀏覽過的頁面存在這台裝置的快取。按頁尾的「離線儲存我的收藏」，也會把您收藏的平台頁面（最多 40 頁）存進去。副本只留在裝置上，最多 60 頁，超過 30 天不再使用；按「清除本站儲存資料」也會一併刪除。

流量統計（Cloudflare Web Analytics）

本站使用 Cloudflare, Inc.（美國）的 Cloudflare Web Analytics 了解整體流量。Cloudflare 會在網頁送出時加入一段測量程式，載入後把測量資料送到 Cloudflare。根據 Cloudflare 的說明，統計包含下列項目：

  • 網域與頁面網址的路徑
  • 從哪個網站連過來
  • 國家
  • 裝置類型、瀏覽器與作業系統
  • 頁面的載入方式、載入時間與 Core Web Vitals

根據 Cloudflare 的說明，這項統計不使用 Cookie 或 localStorage，也不跨網站追蹤個別訪客。站長在 Cloudflare 後台看到的，是依頁面、國家等項目彙整的統計。

您在搜尋欄輸入的文字在瀏覽器內比對，但會寫進網址的 ?q= 參數。網址是頁面載入時請求的一部分，測量程式也讀得到頁面網址；根據 Cloudflare 的說明，這項統計不記錄網址問號之後的參數。

詳見 Cloudflare 隱私權政策（開啟新分頁）、Web Analytics 介紹（開啟新分頁）與 Web Analytics 常見問題（開啟新分頁）。

流量統計（Google Analytics，需要您同意）

本站使用 Google LLC（美國）的 Google Analytics 4，了解哪些頁面被看、哪些連結被點，用來改善內容。只有在您按下「同意」之後，本站才會向 Google 載入它的腳本（gtag.js）；不同意或沒有做選擇，本站不載入它，也不會向 Google 傳送任何資料。

您同意後，依 Google 的說明，Google Analytics 預設會設定下列 Cookie：

  • _ga：用來區分使用者，預設有效期限 2 年。
  • _ga_ 開頭的 Cookie，後面接 Google Analytics 的容器代碼：用來保存工作階段狀態，預設有效期限 2 年。

依 Google 的說明，預設會蒐集的資料包含：頁面瀏覽、您的裝置與瀏覽器資訊、在網站上的活動（離開本站的連結點擊也可能包含在內，例如您按「立即註冊」前往平台那一下），以及由 IP 位址推得的大致所在位置（可能到城市）。Google 說明：歐盟、瑞士與英國使用者的個別 IP 位址不會被記錄或儲存，只用來推得所在位置；其他地區使用者的 IP 位址會用於基本服務運作、垃圾流量偵測與推得大致位置，原始 IP 位址不與使用者識別碼連結，使用後即捨棄。載入腳本時，Google 一定會收到您的 IP 位址與瀏覽器資訊，這和載入任何第三方資源相同。

本站已關閉 Google 訊號與廣告個人化，也不把這些資料用於廣告。事件資料的保留期限由站長在 Google Analytics 設定，標準版只提供 2 個月與 14 個月兩種選擇；本頁不寫死目前的設定值。

若您的瀏覽器送出 Global Privacy Control（GPC）訊號，在您自己選擇之前，本站視為「不同意」，也不顯示橫幅；您仍可隨時在頁尾的「統計設定」選擇同意。

您可以隨時撤回同意：按頁尾的「統計設定」並選「不同意」，本站會停止傳送資料並刪除上述 Cookie。也可以使用 Google 提供的 Google Analytics 不透露資訊瀏覽器外掛程式（開啟新分頁）。

詳見 Google Analytics 使用的 Cookie（開啟新分頁）、Google 如何使用來自使用其服務之網站或應用程式的資訊（開啟新分頁）與 Google 隱私權政策（開啟新分頁）。

託管與網路服務

本站的檔案由 GitHub Pages（GitHub, Inc.）託管，流量經過 Cloudflare, Inc. 的代理服務。與任何主機或代理一樣，兩者都會收到您的 IP 位址、請求的網址與請求標頭，並依各自的政策處理。根據 GitHub 的說明，造訪 GitHub Pages 網站時，會記錄並儲存訪客的 IP 位址（用於安全目的），詳見 GitHub Pages 說明（開啟新分頁）。本站自己不另外蒐集或保存這些資料。Cloudflare 的代理服務如果設定 Cookie，依 Cloudflare 自己的政策處理。

離開本站

推薦連結會前往各平台的網站，適用各平台自己的隱私權政策。透過推薦連結註冊時，本站可能獲得回饋（見頁尾的說明）。按下分享按鈕時，您分享的頁面網址與分享文字會交給 LINE、WhatsApp、Telegram 或系統的分享面板，之後適用該服務自己的政策；本站不記錄分享。字型、圖示與 QR Code 都由本站自己提供；除了 Cloudflare 的測量程式，以及您同意之後才載入的 Google Analytics，頁面不向其他第三方請求資源。
